# Créditos de áudio

Os efeitos de interface em WAV neste diretório vêm do pacote **Interface Sounds** de Kenney.

- Fonte: https://kenney.nl/assets/interface-sounds
- Autor: Kenney Vleugels (https://kenney.nl)
- Licença: Creative Commons Zero (CC0 1.0)
- Cópia da licença incluída no pacote original: `LICENSE.txt` (conteúdo CC0).

Os efeitos são usados em volume baixo para feedback de interface. A preferência de mudo é salva localmente. Nenhum som toca até uma interação do usuário.
